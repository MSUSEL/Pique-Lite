# Project Comparison

The **Project Comparison** page allows you to compare the quality of different projects.

## Navigating to the Comparison Page

To access this page, click on the **Comparison** tab in the navigation bar.  
<br />
<img src="/assets/images/switch-to-compare-page.png" class="small-img" alt="Navigation tab to Project Comparison page" />

## Understanding the Comparison Graph

<img src="/assets/images/project-compare-page.png" class="medium-img" alt="Project comparison page" />

This page lets you compare multiple projects based on a single quality aspect. The graph displays:

- **Two colored lines**, each representing a project’s score for the selected quality aspect
- A **hover feature** that shows the exact scores for each project at a given version
- The ability to **zoom in** on specific time ranges to analyze trends more closely

<img src="/assets/images/project-compare-page-zoomed.png" class="medium-img" alt="Project comparison page" />

## Interacting with the Graph

### Hover for Detailed Information  

- Move your mouse over any version to see the scores for each project

<img src="/assets/images/project-comparison-hover.png" class="medium-img" alt="Project comparison page" />

### Zoom & Crop Feature

- Select a range of versions to zoom in and focus on changes over time
- Click the **Zoom Out Magnifier** button to return to the full graph view  

<img src="/assets/images/project-comparison-crop.png" class="medium-img" alt="Project comparison page" />

**Zoom results**:

<img src="/assets/images/project-comparison-crop-results.png" class="medium-img" alt="Project comparison page" />


## Selecting Quality Aspects  

Above the graph, you can use the dropdown to switch between different quality aspects:  

  - Availability  
  - Authenticity  
  - Authorization  
  - Confidentiality  
  - Non-repudiation  
  - Integrity  

The graph updates automatically to show project scores for the selected aspect.

<img src="/assets/images/switch-quality-aspect.png" class="medium-img" alt="Switch quality aspect on project comparison page" />
