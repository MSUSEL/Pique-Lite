# User Guide  

Welcome to the **PIQUE User Guide**! 

This section walks you through how to use PIQUE, from uploading input files to understanding software quality metrics.  

### What's in this guide?  

- **[Input Schema](input-schema/input-schema.md):** Learn about the required JSON format and how to prepare your data for analysis 
- **[Handling Input Errors](input-schema/input-errors.md):** Common issues with input files and how to fix them
- **[Core Features](core-features/file-upload.md):** Key functionalities like uploading files, exploring results, and interpreting metrics
- **[Advanced Features](advanced-features/tree-display.md):** Customizing analysis with hierarchical views, adjusting category weights, and fine-tuning metrics

Each section provides step-by-step instructions to help you get the most out of PIQUE. If you're new, start with **Input Schema** to ensure your files are set up correctly.
